📐 Introduction to Linear Polynomials

Class 9 Mathematics — Ganita Manjari

📖 Chapter Overview

A linear polynomial is a polynomial whose highest power of the variable is 1. In this chapter, we learn how to identify, evaluate and work with linear polynomials.

🔢 What is a Linear Polynomial?

A polynomial of the form ax + b, where a ≠ 0, is called a linear polynomial.

Examples

  • x + 5
  • 2x - 3
  • 7x + 1
  • 5x

⭐ Degree of a Linear Polynomial

The highest power of the variable in a linear polynomial is 1.

Therefore, every non-constant linear polynomial has degree 1.

Example: 3x + 7 → Degree = 1

🎯 Value of a Polynomial

To find the value of a polynomial for a particular value of x, substitute that value in the expression.

Example

Find the value of 2x + 3 when x = 4.

Show Solution

2x + 3

= 2(4) + 3

= 8 + 3

✅ Answer = 11

🎯 Zero of a Linear Polynomial

The zero of a polynomial is the value of x for which the polynomial becomes zero.

Example

Find the zero of 2x + 6.

Show Solution

2x + 6 = 0

2x = -6

x = -3

✅ Zero = -3

🧠 Important Points

  • A linear polynomial has degree 1.
  • Its general form is ax + b, where a ≠ 0.
  • A linear polynomial has exactly one zero.
  • The zero is the value of x that makes the polynomial 0.
  • To evaluate a polynomial, substitute the given value of x.

✏️ Solved Examples

Example 1

Identify the linear polynomial: 3x + 8.

Show Answer

The highest power of x is 1.

✅ Therefore, 3x + 8 is a linear polynomial.

Example 2

Find the value of 5x - 2 when x = 3.

Show Solution

5(3) - 2 = 15 - 2 = 13

✅ Answer = 13

Example 3

Find the zero of 3x - 12.

Show Solution

3x - 12 = 0

3x = 12

x = 4

✅ Zero = 4
