🧮 Exploring Algebraic Identities

Class 9 Mathematics — Ganita Manjari

📖 Chapter Overview

Algebraic identities are equations that remain true for all permissible values of the variables. They help us simplify expressions and perform calculations quickly.

⭐ Important Algebraic Identities

1. Square of a Sum

(a + b)² = a² + 2ab + b²

2. Square of a Difference

(a - b)² = a² - 2ab + b²

3. Difference of Two Squares

a² - b² = (a + b)(a - b)

4. Product of Two Binomials

(x + a)(x + b) = x² + (a + b)x + ab

🔍 Understanding an Identity

Consider:

(a + b)² = a² + 2ab + b²

This remains true for every value of a and b. Therefore, it is an algebraic identity.

✏️ Solved Examples

Example 1

Expand: (x + 3)²

Show Solution

(x + 3)²

= x² + 2(x)(3) + 3²

= x² + 6x + 9

✅ Answer = x² + 6x + 9

Example 2

Expand: (x - 5)²

Show Solution

(x - 5)²

= x² - 2(x)(5) + 25

= x² - 10x + 25

✅ Answer = x² - 10x + 25

Example 3

Simplify: 25² - 15²

Show Solution

Using a² - b² = (a + b)(a - b)

= (25 + 15)(25 - 15)

= 40 × 10

✅ Answer = 400

Example 4

Expand: (x + 2)(x + 5)

Show Solution

= x² + (2 + 5)x + (2 × 5)

= x² + 7x + 10

✅ Answer = x² + 7x + 10

🧠 Important Points

  • An identity is true for all permissible values of the variables.
  • Use identities to expand algebraic expressions quickly.
  • Remember the signs carefully when using (a - b)².
  • The identity a² - b² is useful for quick calculations.
