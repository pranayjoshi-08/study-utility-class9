Exploring Sequences and Progressions

📘 Class 9 Mathematics — Ganita Manjari

📖 Chapter Overview

A sequence is an ordered list of numbers or objects formed according to a particular rule.

In this chapter, we learn how to identify patterns, predict terms and describe sequences using mathematical rules.

🔢 What is a Sequence?

A sequence is a list of numbers arranged in a definite order. Each number is called a term.

Example:

2, 4, 6, 8, 10, ...

Here the terms increase by 2 each time.

🔍 Finding Patterns

Example 1

1, 2, 3, 4, 5, ...

Pattern: Add 1 to get the next term.

Next terms: 6, 7, 8, 9, ...

Example 2

2, 5, 8, 11, ...

Pattern: Add 3 each time.

Next terms: 14, 17, 20, ...

Example 3

1, 4, 9, 16, 25, ...

These are square numbers:

1², 2², 3², 4², 5², ...

🔺 Triangular Numbers

The triangular number sequence is:

1, 3, 6, 10, 15, 21, ...

Each term is obtained by adding the next natural number.

The nth triangular number is:

Tₙ = n(n + 1) / 2

For example:

T₅ = 5 × 6 / 2 = 15

📐 General Term

A general term is a formula that gives the value of any term when its position is known.

The position of a term is usually represented by n.

Example

For the sequence:

2, 4, 6, 8, 10, ...

The nth term is:

tₙ = 2n

Therefore:

t₁₀ = 2 × 10 = 20

🔄 Recursive Rule

A recursive rule defines a term using one or more previous terms.

Example:

a₁ = 2

aₙ = aₙ₋₁ + 3

This produces:

2, 5, 8, 11, 14, ...

📈 Arithmetic Progression (AP)

An arithmetic progression is a sequence in which the difference between consecutive terms is constant.

Example:

5, 8, 11, 14, 17, ...

Common difference:

d = 8 − 5 = 3

🧮 nth Term of an AP

If the first term is a and the common difference is d, then:

tₙ = a + (n − 1)d

Example

Find the 10th term of:

3, 7, 11, 15, ...

a = 3

d = 4

t₁₀ = 3 + (10 − 1) × 4

t₁₀ = 3 + 36

✅ t₁₀ = 39

📊 Geometric Progression (GP)

A geometric progression is a sequence in which each term is obtained by multiplying the previous term by a fixed number.

Example:

2, 6, 18, 54, ...

Common ratio:

r = 6 ÷ 2 = 3

🧮 nth Term of a GP

If the first term is a and common ratio is r, then:

tₙ = arⁿ⁻¹

Example

Find the 5th term of:

2, 4, 8, 16, ...

a = 2

r = 2

t₅ = 2 × 2⁴

t₅ = 2 × 16

✅ t₅ = 32

📋 AP vs GP

Arithmetic Progression Geometric Progression
Fixed difference Fixed ratio
Add or subtract the same number Multiply or divide by the same number
Example: 3, 7, 11, 15 Example: 3, 6, 12, 24

🌍 Sequences in Real Life

Patterns and progressions can be found in many situations, such as:

  • Growing populations
  • Financial calculations
  • Repeated measurements
  • Patterns in nature
  • Computer algorithms
  • Geometric designs

⭐ Important Formulas

  • Triangular number: Tₙ = n(n + 1)/2
  • AP nth term: tₙ = a + (n − 1)d
  • GP nth term: tₙ = arⁿ⁻¹
  • AP common difference: d = second term − first term
  • GP common ratio: r = second term ÷ first term
