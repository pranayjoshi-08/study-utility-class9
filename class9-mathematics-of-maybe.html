📖 Chapter Overview

Probability is the mathematical study of uncertainty. It helps us measure how likely an event is to happen.

We use probability in everyday situations such as weather forecasts, games, surveys, sports and experiments.

🎯 What is Probability?

Probability tells us how likely an event is to occur.

Probability is represented by P(E), where E represents an event.

The value of probability always lies between:

0 ≤ P(E) ≤ 1

📊 Probability Scale

  • 0 → Impossible
  • Between 0 and 0.5 → Less likely
  • 0.5 → Equally likely
  • Between 0.5 and 1 → More likely
  • 1 → Certain

The closer the probability is to 1, the more likely the event is to happen.

The closer it is to 0, the less likely the event is.

🎲 Random Experiment

A random experiment is an experiment whose possible outcomes are known, but the exact outcome cannot be predicted with certainty before the experiment.

Examples

  • Tossing a coin
  • Rolling a die
  • Picking a coloured pen randomly
  • Drawing a card from a set of cards

🔢 Outcomes

An outcome is a possible result of a random experiment.

Example: Tossing a Coin

Possible outcomes are:

H = Heads

T = Tails

Therefore:

S = {H, T}

📦 Sample Space

The set containing all possible outcomes of a random experiment is called the sample space.

One Coin

S = {H, T}

One Die

S = {1, 2, 3, 4, 5, 6}

Two Coin Tosses

S = {HH, HT, TH, TT}

Notice that HT and TH are different outcomes.

🎯 Events

An event is a particular outcome or collection of outcomes from the sample space.

Example

When a die is rolled, the event of getting an even number is:

E = {2, 4, 6}

🧮 Theoretical Probability

When all possible outcomes are equally likely, the probability of an event E is:

P(E) = Number of favourable outcomes / Total number of possible outcomes

🪙 Example: Tossing a Coin

What is the probability of getting Heads when a fair coin is tossed?

Show Solution

Sample space: S = {H, T}

Favourable outcomes = 1

Total outcomes = 2

P(H) = 1/2

✅ Answer = 1/2

🎲 Example: Rolling a Die

What is the probability of getting an even number when a fair die is rolled?

Show Solution

Sample space: {1, 2, 3, 4, 5, 6}

Even outcomes: {2, 4, 6}

Favourable outcomes = 3

Total outcomes = 6

P(E) = 3/6 = 1/2

✅ Answer = 1/2

📈 Experimental Probability

Experimental probability is based on actual results obtained by performing an experiment.

It is calculated as:

Experimental Probability = Frequency of the event / Total number of trials

Example

A coin is tossed 20 times and Heads appears 12 times.

Experimental probability of Heads:

12/20 = 3/5

🔬 Experimental vs Theoretical Probability

Experimental Probability Theoretical Probability
Based on actual experiments Based on possible outcomes
Uses observed frequency Uses favourable outcomes
May change from experiment to experiment Fixed when outcomes are equally likely

🌳 Tree Diagrams

A tree diagram is a useful way of showing all possible outcomes of a multi-step experiment.

Two Coin Tosses

First toss:

  • H
  • T

From each result, the second toss can again be H or T.

Therefore:

S = {HH, HT, TH, TT}

🎨 Example: Coloured Pens

Suppose a student can pick one of three colours: Red, Black or Green.

If a second student also picks one pen, the possible ordered outcomes include:

RR, RB, RG, BR, BB, BG, GR, GB, GG

Total outcomes = 9

Same-colour outcomes: RR, BB, GG

Therefore:

P(Same Colour) = 3/9 = 1/3

⭐ Important Points

  • Probability lies between 0 and 1.
  • An impossible event has probability 0.
  • A certain event has probability 1.
  • The sample space contains all possible outcomes.
  • An event is a selected outcome or collection of outcomes.
  • Experimental probability uses actual observations.
  • Theoretical probability uses possible equally likely outcomes.
  • Tree diagrams help organise multi-step experiments.
